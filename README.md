# Paradise Nursery Shopping Application

## Project Overview
Paradise Nursery is a dynamic React and Redux-based e-commerce web application built for an online plant shop. Users can browse a curated collection of houseplants across multiple categories, view plant details, add items to their shopping cart, and dynamically manage cart quantities and total costs.

## Features
- **Landing Page:** Welcoming interface featuring the company name, mission, and a "Get Started" button to enter the store.
- **Product Listing:** Displays houseplants organized into distinct categories (Air Purifying Plants, Aromatic Fragrant Plants, and Insect Repellent Plants) with thumbnails, descriptions, and prices.
- **Shopping Cart Management:** Allows users to add items, prevent duplicate additions via button state management, increment/decrement quantities, remove items, and view real-time total costs.
- **Responsive Navigation:** Persistent navigation bar displaying dynamic cart item counts.

## Technologies Used
- React
- Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- CSS3
